  Model Diversity:
  - Single model vs 2-model vs 3-model ensembles
  - Which models complement each other's blind spots?
  - Cost/benefit analysis of ensemble vs flagship

  Philosophical Framings:
  - Ayni (reciprocity) vs Kantian (categorical imperative) vs Ubuntu vs Confucian
  - Do different frameworks catch different attack types?
  - Cross-tabulate: Framework × Attack Pattern → Detection Rate

  REASONINGBANK Pattern Analysis → Fire Circle Meta-Evaluation:

  The critical innovation:
  1. Pattern Analyzer reviews REASONINGBANK data:
    - Clusters similar attack patterns
    - Identifies what pre-eval missed but post-eval caught
    - Suggests observer framing improvements: "Add explicit check for X pattern"
  2. Fire Circle deliberates on proposals:
    - "Should we add 'role reversal detection' to observer framing?"
    - Models debate: Does this improve detection or create false positives?
    - Consensus decision on framing change
  3. A/B test the change:
    - Run validation with old framing vs new framing
    - Measure: Did it reduce false negatives without increasing false positives?
  4. If validated → update observer framing, else → reject proposal

  This is where Fire Circle becomes the Supreme Court:
  - Not evaluating individual prompts (SINGLE mode does that)
  - Evaluating changes to the evaluation framework itself
  - Meta-evaluation: "Is this framing improvement legitimate?"
